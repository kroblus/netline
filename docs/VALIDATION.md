## 可复现自动化

JVM `StatisticsTest` 共 13 项：有效时长加权平均；合法零速率与缺失区分；极值重复取最早；60 秒/5 分钟/完整范围；边界不插值；无数据拒绝；会话边界检查；两个方向的降采样峰谷和时间顺序；分钟汇总峰谷与缺失；旧数据不可用字段；原始数据优先避免重复统计；并列旧峰值时间不可知；计数器复位/不支持/休眠/时钟变化；有效空闲流量。其中个别测试同时覆盖多个场景。

手机测试：

1. `migrationPreservesLegacyRowsAndUnknownExtrema`：保留会话和字节总数，谷值/时间保持 NULL，旧覆盖信息未知。
2. `providerRejectsFilesOutsideExportDirectory`：拒绝分享导出目录以外的内部文件。
3. `failedSaveRemovesPendingMediaRow`：源文件缺失时保存失败，清除未完成 MediaStore 行。
4. `reportSnapshotPngMediaStoreAndSecureProvider`：隔离数据库内 6 分钟明确标记的合成夹具，含零速率、明显峰值和 11 秒缺失；生成及解码 PNG、保存/重复保存相册、IS_PENDING 完成、FileProvider URI、导出后继续追加。测试相册文件随后清理。
5. `floatingBallAndSingleSamplerOnAndroid16`：真实采样入库，桌面开始/停止并待机；拖动不创建会话；长按与外部关闭不触发记录；菜单打开主界面；30 次快速请求只创建一次会话；浏览器及设置可见；横竖屏边界；记录中导出不阻塞后续采样；隐藏后继续记录；真正点击通知栏停止；空闲服务释放。
6. `realTrafficReportCrossUidReadGrant`：从真实已结束会话生成 PNG，通过具有读授权的 content URI 发送给独立测试 APK/UID，显示 `PNG OK 1080 x 1920`。没有发消息给任何联系人。

`docs/test-fixture-report.png` 仅展示隔离测试夹具的排版及缺失区间，**不是用户真实网络记录**。真实报告保存在手机相册，本地验收图片与手机 UI 抓取均排除出 Git。

## 额外真机手动界面验证

除 instrumentation 外，通过手机实际界面完成：

- 用户首次进入魅族悬浮窗权限设置并授权；拒绝/未授权状态没有强制阻止核心界面。
- 手动创建真实会话 #3，`09:43:48 — 09:50:01`，期间切换桌面、锁屏及返回，采样继续。
- 正在记录时从页面生成完整快照、末尾 60 秒报告；60 秒图片实际写入 `Pictures/NETLINE/`。
- 从会话 #3 选择末尾 5 分钟，生成 `09:45:01 — 09:50:01` 真实流量报告并保存；查看 PNG，确认双曲线、峰谷/时间、统计、真实时间轴、中文尾注与完整布局。
- 手动点击 SHARE IMAGE，Android 系统图片分享面板正常打开；没有选择微信/QQ 联系人实际发送。
- 预览原始比例下从图片中间单指上下滚动，可到达保存、分享按钮。最初发现缩放手势吞掉滚动，已修复并在手机确认。
- 启用待机悬浮球后在 Custom Range 起始时间输入框打开键盘，系统 `mInputShown=true`，悬浮视图仍存在；输入焦点保留在文本框，悬浮窗口仅 56dp，无大面积输入拦截。
- 运行中使用标准 ADB AppOps 测试撤销已授予的悬浮权限：WindowManager 不再存在 NETLINE 悬浮视图，正在运行的记录仍可从主界面正常停止；在无悬浮权限状态下再次开始记录也正常。测试后恢复用户之前明确授予的权限。
- 记录会话 #7 时使用 `am force-stop com.netline.app` 模拟用户终止，重新打开后显示 INTERRUPTED，历史按最后提交数据结束；没有后台循环重启，也没有自动重新显示悬浮球。

## 安装工具限制与复现注意

首次 ADB 安装曾返回 `INSTALL_FAILED_USER_RESTRICTED`，由用户在手机授权后成功。曾有一次 Gradle `connectedDebugAndroidTest` 成功执行 5 项测试；后续 Gradle split 安装被厂商限制，且清理安装使数据/权限重置，因此后续改为普通 `adb install -r` + `am instrument`。权限重置后未授权的跳过结果没有作为验收通过；恢复用户授权后重新执行，全部通过。

不要在已有重要记录的个人手机上直接运行可能清理应用的 Gradle connected 任务。README 提供保留安装的数据安全复现方式。应用只声明悬浮窗、前台服务及通知相关权限；打包清单已确认无 INTERNET 和通用存储/媒体读取权限。
